# darsa.kz

Одностраничный сайт ТОО «DARSA Solutions» на трёх языках: русском, казахском и английском.
Статика, без фреймворков и зависимостей.

## Структура

```
content.py   тексты всех трёх языков — правим здесь
build.py     разметка, стили и сборка
public/      то, что уезжает на сервер; корень сайта
  index.html      ru
  kk/index.html   kk
  en/index.html   en
  favicon.svg, logo.svg
```

`public/` собирается скриптом — руками файлы там не правим, при следующей сборке
изменения затрутся.

## Как внести правку

```bash
python build.py
```

Нужен только Python 3, пакеты ставить не надо. Команда перезаписывает три страницы
в `public/`. Дальше обычный коммит и пуш — сервер подхватит изменения сам.

Посмотреть локально:

```bash
python -m http.server 8765 -d public
```

## Деплой

Plesk подключён к этому репозиторию и после каждого пуша в `main` забирает файлы
в `httpdocs`. Корень сайта указывает на `httpdocs/public`, поэтому `build.py` и
`content.py` лежат на сервере, но наружу не отдаются.

## Темы и языки

Тема берётся системная, кнопка в шапке переключает и запоминает выбор в
`localStorage`. Языки — три отдельные страницы со своими `canonical` и `hreflang`,
переключатель в шапке.

## Подтверждение прав Google

`GOOGLE_SITE_VERIFICATION` и `GA_ID` в `content.py` пустые. Если заполнить, сборка
добавит мета-тег подтверждения или счётчик GA4 в `<head>` всех трёх страниц.
Сейчас владение подтверждается файлом `public/google24c21a348bbca899.html`.
